# What is a Student Die?
A Student Die is a **1d4 bonus die** that can be added to skill checks.

# Sources of Student Dice
- [[2-Player Handouts/Academic Information/Extracurricular Clubs/Extracurriculars List\|Extracurricular Clubs]]
- Guild Membership
- Successful [[3-Homebrew Mechanics/Academics/Neverwood Academic System\|Exams]]

# Refresh Rules
- Club & Guild dice: refresh **every tenday**
- Exam dice: **one-time** use only

# Upgrading Dice
Student Dice improve via Student Skill Points:
- Typically increase die size (e.g. 1d4 → 1d6 → 1d8)
- Requires investment in relevant [[3-Homebrew Mechanics/Academics/Student Skills System\|skill category]]
